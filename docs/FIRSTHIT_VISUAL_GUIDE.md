## 🎯 快速判断流程图

```
第一步：检测到 DOWN 报价首次进入 (0.005, 0.1]?
  ├─ 是 → 继续
  └─ 否 → 放弃（无首触）

第二步：计算 body_r = |btc 触发 − 开盘| / (max−min)?
  ├─ body_r ≤ 0.35? → G1 通过，继续
  └─ body_r > 0.35? → G1 拒绝，G4/G7 也无法通过

第三步：计算 chg_bps = (btc 触发 − 开盘)/开盘 × 1e4?
  ├─ chg_bps ≤ +2.82? → G3 通过，G4 有机会
  └─ chg_bps > +2.82? → G3 拒绝，G4 不可能

第四步：检查 wick01 = 路径高点 > max(btc 触发，开盘)?
  ├─ wick01 == 1? → G7 基础条件满足
  └─ wick01 == 0? → G7 拒绝

第五步：检查衍生条件 (streak/uppper_wick/q/td)?
  ├─ 符合变体条件? → 该版本触发
  └─ 不符合？→ 该版本不触发

第六步：同窗互斥检查
  ├─ 本窗已有其他通道成交? → 放弃
  └─ 可开火 → 提交订单
```

## 🔍 实盘快速自查表

每次看到订单时问自己：

1. **首触位置**: DOWN 报价是否在 0.005-0.1 区间内？
2. **BTC 走势**: 是暴涨暴跌还是温和震荡？
3. **是否有冲高**: 盘中曾高于开盘价吗？
4. **连阳情况**: 前几个 5m 窗口都是阳线吗？
5. **触发时机**: 是在窗口前半段还是快结束了？

根据回答对应到各个版本的 K 线要求！
