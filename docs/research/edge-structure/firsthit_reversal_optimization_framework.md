# G0/G1/G3 首触反转信号优化设计规范 (First-Hit Reversal Scientific Optimization Spec)

**目标**：针对线上现行 5m 预测市场首触反转族信号（G0/G1/G3），采用科学假设驱动（Scientific Hypothesis-Driven）方法，在“过滤降频、追求高胜率与高单注 EV”指导原则下穷尽优化维度，形成具有严密统计验证闭环的升级方案。

---

## 1. 现状基线与痛点诊断

### 1.1 现行线上版本
- **G0 (`firsthit_down_v1`)**：基底，5m 窗内 DOWN 报价首次进入 `(0.005, 0.1]` 即触发；胜率 ~8.5%~9.2%，EV 约 +0.21~+0.28（日聚类 CI 下界接近 0）。
- **G1 (`firsthit_down_body_v1`)**：小实体门禁 `body_r ≤ 0.35`；胜率 ~14.0%~17.9%，EV 约 +1.44~+1.59（BH-FDR q=0.007）。
- **G3 (`firsthit_down_chg_v1`)**：价格位移门禁 `chg_bps ≤ +2.82bp`；胜率 ~9.3%~16.0%，EV 约 +0.39~+0.97。

### 1.2 物理矛盾与优化突破口
1. **反转发生的时间物理约束**：DOWN 在 5m 窗内跌破 0.10，代表 BTC 涨势凶猛；最终 DOWN 要赢，BTC 必须在窗内剩余时间内跌回开盘价以下。若触发过晚，均值回归在物理上缺乏时间扩散空间。
2. **多头衰竭证据的缺失**：G0 无任何形态约束；G3 仅约束位移幅度，未确认冲高是否受阻；只有确认多头在局部“冲高并遭遇密集拒绝”（长上影、流动性掠夺），反转胜率才能出现阶跃式提升。
3. **赔率与进场价的钝化**：现行护栏（G1: 0.12, G3: 0.09）较为宽松，部分成交在赔率边际不足的 0.08~0.10 区间，稀释了整体期望。

## 2. 五维科学假设矩阵与度量指标

| 假设编号 | 物理机理假说 | 衍生量化特征 (Ex-Ante) | 假设检验零假设 ($H_0$) 与通过判据 |
| :--- | :--- | :--- | :--- |
| **H1 (形态拒止)** | 多头冲高伴随买盘耗尽，形成上影线拒绝后均值回归胜率显著高于光头阳线。 | `wick01` (二元上影) / `upper_wick_ratio` = $(cum\_hi - \max(Bo, Bt)) / rng$ | **$H_0$**: $\beta_{wick} \le 0$ (控制时间 $t$ 协变量后)。<br>**通过**: Logit $\beta > 0$ 且 $p < 0.01$；日聚类 CI 下界 > 0。 |
| **H2 (时空扩散)** | 均值回归需要充分的布朗运动时间扩散；过晚触发或离平价太远，回归概率指数衰减。 | $\Delta t_{remain} = 300 - t$；<br>标准化距离 $Z = \frac{BTC_t - BTC_o}{\sigma_{1m} \sqrt{\Delta t_{remain}/60}}$ | **$H_0$**: 晚触发桶 ($t > 220s$) EV 与早触发桶无差异。<br>**通过**: $Z \le 1.2$ 显著提升胜率，剔除尾部失效率。 |
| **H3 (赔率精细化)** | 超深折价 ($q \le 0.04$) 具备极高的非对称凸性赔率 ($\ge 23.5\times$)，其正向 EV 远高于 $q \in (0.06, 0.10]$。 | 首触真实报价 $q_{entry}$，分档划分为 $[0.005, 0.04]$ 与 $(0.04, 0.08]$ | **$H_0$**: 深浅档的净期望收益相同。<br>**通过**: 限制进场护栏上界大幅提升平均单注 EV。 |
| **H4 (高阶趋势抑制)**| 顺应更高时间周期（15m/1h）的趋势，在强单边多头主升浪中逆势押注反转极易遭遇轧空。 | 前驱 15m K 线状态、连续阳线计数 `streak_up`、日内位移分位数 | **$H_0$**: 宏观处于极强多头时，首触反转胜率不下降。<br>**通过**: 在单边趋势强市下执行静默熔断，显著降低最大回撤。 |
| **H5 (微观量价背离)**| 价格创窗内新高但参与人数 $\Delta par$ 与成交额 $\Delta vol$ 未放量，表明为买方流动性真空诱多。 | $\Delta vol / \Delta par$ 弹性；预测市场内部盘口深度消耗比 | **$H_0$**: 假突破与真突破在盘口量能变化上无统计差异。<br>**通过**: 配合成交量背离过滤，胜率提升 $\ge 3\%$。 |

## 3. 落地优化版本演进设计 (Target Architectures)

### 3.1 核心推荐：G7 升级版（正交小实体 + 上影拒止，`firsthit_down_g7_v1`）
- **触发逻辑**：
  1. DOWN 首次进入 `(0.005, 0.1]`；
  2. 满足质量门 `npts ≥ 8`（严禁稀疏路径假特征）；
  3. `body_r ≤ 0.35`（实体归一占比不高，非全长单边推升）；
  4. `wick01 == 1.0`（$cum\_hi > \max(BTC_{trig}, BTC_{open})$，且上影线长度 $> 1.0$ bp）；
  5. 严格时间门禁 $t \le 210s$（确保至少留有 90s 均值回归窗口）。
- **执行层护栏**：
  - 静态执行价护栏下调至 `0.065`（回测平衡价 $0.20 \times 0.98 = 0.196$ 的极深保守水准，只在赔率极度有利时成交）。

### 3.2 进阶推荐：时空 Z 距离自适应版（`firsthit_down_zdist_v1`）
- 在 G7 基础上叠加 $Z_{fade} \le 1.2$，使极端脉冲单边行情的胜率损失降为 0。

## 4. 验证与上线纪律（Validation & Governance Gate）

1. **样本切分纪律**：严格锁定 `2026-08-24` 切分点（Calib vs Confirm）；Confirm 段绝不用于参数调优。
2. **多重检验校正**：所有新门禁候选必须经过 Benjamini-Hochberg FDR ($q \le 0.05$) 检验。
3. **前向影子裁决期**：新版本入库 `firsthit_shadow_signals` 作为专用影子通道验证 4 周，满足：
   - 样本量 $N \ge 30$；
   - 经验胜率 $P \ge 18\%$；
   - 日聚类 Bootstrap 95% CI 下界 $> 0$。
4. **零破坏实盘安全**：保持现行 G0/G1/G3 实盘通道独立运作，新增优化版本以新 version ID 注册，不影响既有订单流水。
