### 1.3 明确证伪的负向因子

- **强连阳 (`streak_up≥2`)**：Calib EV=**-0.01**（P=7.7%），FDR-q=0.9510。逆势反转在多头单边中失效，应作 Hard Veto。
- **强突破前高 (`break>10bp`)**：Calib EV=**-0.67**，CI[-1.00,-0.08]，FDR-q=0.9997。真突破后反转几乎必败。
- **超深折价 (`q≤0.03`)**：Calib P 仅 3.6%，虽赔率高但胜率过低，EV CI 跨 0，FDR-q=0.9997。

## 2. 修订后落地建议

### 2.1 首选：`G7+非强连阳`（即原 ALPHA_G7_CORE，去除冗余命名）
- **规则**：`body_r ≤ 0.35` ∧ `wick01 == 1.0` ∧ `streak_up ≤ 1`
- **依据**：FDR-q=0.0004（最强显著性之一）；两期样本均 n≥77；Calib/Confirm EV 均 >+1.9 且 CI 下界 >+0.45。
- **频次**：Calib 25 天 125 单 ≈ 日均 5 单，Confirm 15 天 77 单 ≈ 日均 5 单，容量适中。

### 2.2 次选：`G7 组合`（不加 streak 门，频次更高）
- **规则**：`body_r ≤ 0.35` ∧ `wick01 == 1.0`
- **依据**：FDR-q=0.0002；Confirm 胜率 20.0%（最高）；样本量更大（n=170/90）。
- **权衡**：未剔除强连阳，Calib EV(+2.34) 略低于加 streak 门版本，但样本更稳健。

### 2.3 必加负向门禁（Hard Veto）
- `streak_up ≥ 2` 全局静默（强连阳逆势必亏）。
- `break_bps > 10` 全局静默（真突破后反转必败）。

### 2.4 不推荐（尽管 EV 数字诱人）
- `G7+非极晚`、`G7+假突破`、`G7+深折价`：Confirm 样本 n<30，CI 过宽或跨 0，属小样本噪音，**不可仅凭回测上线**。
