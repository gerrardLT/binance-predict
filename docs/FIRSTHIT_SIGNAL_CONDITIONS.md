## 🎯 通用触发规则（所有版本共享）

### 第一步：首触判定（Common Trigger Condition）
```python
Q_LO, Q_HI = 0.005, 0.1  # 报价区间 (0.005, 0.1]

# DOWN token 报价首次进入该区间 → 标记为"首触时刻"
DOWN 曲线采样中第一个满足 0.005 < down_price ≤ 0.1 的点
```

**通俗解释**:
- 看 DOWN token 价格走势图
- 找到第一次跌到 0.005~0.1 这个区间的时点
- 这个时点就是"首触时刻"，在此刻买入 DOWN

## 📊 各版本 Gate 条件详解

### G0: firsthit_down_v1 - 基底对照组 ✅ **无条件**

**下单条件**:  
只要有首触就开火，无任何筛选

**K 线形态**:
```
任何形状的都算！(无门槛)
BTC 价格走势：随意上下波动
DOWN 报价：只要首次进入 0.005-0.1 区域即可
```

**适用场景**: 基准对照，观察所有首触事件的自然胜率

### G1: firsthit_down_body_v1 - 小实体门 ⭐

**下单条件**:  
✅ body_r ≤ 0.35

**公式定义**:
```python
body_r = |btc@触发 − 开盘| / (路径 max − min)
```

**含义解读**:
- **分子**: 触发时 BTC 相对开盘价的偏离幅度
- **分母**: 从开盘到触发这段路的最大波动范围
- **结果**: 归一化的实体大小

**K 线形态图示**:
```
高价位
  │      ╱╲
  │     ╱  ╲    ← 分母：整个路径的波峰波谷差值较大
  │    ╱    ╲
  │   ╱      ╲
  │  ╱        ╲
  │ ╱          ╲
  │╱            ╲───── 触发点 (btc_trig)
  │              ╲
  │               ╲
低价位 ───────────┴────→ 时间
         ↑
      开盘价

关键点：
- 从开盘到触发，BTC 总体没有剧烈波动
- body_r 小说明"实体"较小，趋势未定型
- 适合反转策略：市场还没方向时就出现首触
```

**典型案例**:
- BTC 在窗口前半段平稳震荡
- 突然在某时刻 DOWN 报价触及低点区间
- 此时 BTC 相对开盘价偏离不大

---

### G3: firsthit_down_chg_v1 - 价格偏离门 ⭐

**下单条件**:  
✅ chg_bps ≤ +2.82

**公式定义**:
```python
chg_bps = (btc@触发 − 开盘) / 开盘 × 1e4  (单位：基点)
```

**含义解读**:
- 触发时 BTC 相对开盘价的涨幅
- ≤+2.82bp = 上涨不超过万分之 28.2
- 实际上是**排除暴涨后的下跌**

**K 线形态图示**:
```
高价位
  │       ╱
  │      ╱    ← 温和上涨或横盘
  │     ╱
  │    ╱
  │   ╱
  │  ╱  chg_bps 很小（≤2.82bp）
  │ ╱
  │╱
  │           ╱
  │          ╱   ← 触发点
  │         ╱
  │        ╱
  └───────┴───→ 时间

禁止的情况：
  │╲
   ╲     ← 暴跌 (chg_bps 负得太多，不符合题意但可能好)
    ╲
     ╲___

   ╱╲      ← 暴涨 (chg_bps > +2.82bp，会被过滤掉)
  ╱  ╲
 ╱    ╲
```

**典型案例**:
- BTC 在触发前只是小幅攀升或横盘
- DOWN 突然见底
- 说明不是 BTC 暴跌导致的 DOWN 下跌（更可能是独立的 DOWN 供需关系变化）

### G4: firsthit_down_g4_v1 - 交互门 ⭐⭐

**下单条件**:  
✅ G1 ∩ G3 = body_r ≤ 0.35 ∧ chg_bps ≤ +2.82

**含义**:
同时满足 G1 和 G3 两个条件

**K 线形态图示**:
```
小实体 + 温和走势的组合
  │      ╱
  │     ╱    ← 涨幅不大
  │    ╱     
  │   ╱  body_r 小
  │  ╱  chg_bps 小
  │ ╱
  │╱
  │      ╱
  │     ╱   ← 触发点 (双重过滤后的高质量样本)
  │    ╱
  └───┴────→
```

**优势**:
- 同时控制了"实体大小"和"价格趋势"
- 筛选出最典型的反转场景
- 研究数据显示 EV(+1.03) 极高

**⚠️ 注意**: G4 ⊂ G1 且 G4 ⊂ G3，同一窗口的 G1/G3/G4 全中时只下一注

### G7: firsthit_down_g7_v1 - 上影拒绝门 ⭐⭐⭐

**下单条件**:  
✅ body_r ≤ 0.35 ∧ wick01 == 1

**公式定义**:
```python
wick01 = 路径高点 > max(btc@触发，开盘) ? 1 : 0
```

**含义解读**:
- 从开盘到触发这段时间内，BTC 曾经冲高过
- 但现在被拉回来了（低于最高点和开盘价）
- "上影线拒绝" = 多头尝试失败

**K 线形态图示**:
```
         ╱‾‾‾‾‾
        ╱      ↖ 高点 (曾冲破此位置)
       ╱
      ╱
     ╱
    ╱
   ╱             wick01=1 ✓
  ╱            ╱
 ╵───────────╱   ← 现在回到低位
          ╱
         ╵  ← 触发点
 
特征：
- 盘中曾冲高，证明多头有力量
- 但随后回落并击穿平衡位
- 留下长上影线 = 多头失败信号
- 配合 small body → 反转概率极高
```

**禁止情况**:
```
╱‾‾‾‾‾‾‾
╱         wick01=0 ✗
↘        (没有冲高过)
 ↘
  ↘
   ↘
    ↘
```

## 🔧 G7 变体家族（G7 + 额外条件）

### g7_streak_v1
**附加条件**: streak_up ≤ 1

**含义**: 
前驱 5m 连续阳线数不超过 1 根
排除强连阳后的反转

**K 线形态**:
```
5m 周期序列:
[🟢][⚪][🔴]  ← OK (streak_up=1 或更少)
 [🟢][🟢][⚪] ← 拒绝 (streak_up=2，太强了)
```

   ╱

 ╱

**附加条件**:

### g7_q05_v1 - 深折价版
**附加条件**: q ≤ 0.05

**含义**:
首触发生在更深的折价区间
比普通的 (0.005, 0.1] 门槛更低

**K 线形态**:
```
DOWN 价格轴:
│
│ 0.10  ← 普通 G7 的下限
│  ↓
│ 0.05  ← g7_q05_v1 的上限
│  ╲
│   ╲
│    ╲
│     ╲  触发点在更深的位置
│      ╲
│ 0.005
```

---

### g7_t270_v1 - 非极晚版
**附加条件**: td_sec ≤ 270

**含义**:
首触发生在窗口的前半段（4 分 30 秒内）
避免尾盘随机波动

**K 线形态时序**:
```
0s     150s     300s
├──────┼───────┤
↑                  ↑
window_start   window_end

g7_t270_v1 要求首触点落在左边 90% 区间
避免最后几十秒的噪声
```

## ⚡ 实盘执行要点

### 1. 特征计算必须在"触发时刻"冻结
- 只使用 ≤trigger_ts 的数据
- 不能偷看未来信息

### 2. Gate 判定顺序
```
Step 1: 检测首触 (down_price ∈ (0.005, 0.1])
Step 2: 提取特征 (chgbps, bodyr, wick01, ...)
Step 3: 逐版评估 gate_of(version, ext)
Step 4: 通过的所有版本都可以下单（同窗互斥例外）
```

### 3. 同窗互斥警告
**重要**: firsthit_down_g1_v1、g3、g4 在同一窗口全中时
- 只会触发一次下单（按 exclusive_group 互斥）
- 不是三门各下一次！
- 实际暴露 = 单注，不是 3 倍
