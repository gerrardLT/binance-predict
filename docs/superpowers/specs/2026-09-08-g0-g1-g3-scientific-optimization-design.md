# G0 / G1 / G3 科学优化研究设计

日期：2026-09-08  
状态：用户已批准研究设计；待书面复核后进入实施计划  
范围：5m DOWN 首触反转族；不改变当前实盘参数，不在本文阶段部署代码

## 1. 结论先行

G0、G1、G3 不是三个独立 alpha，而是同一个 G0 母事件上的两个嵌套标签：

- G0：5m 窗内 DOWN 报价第一次被约 15 秒采样观测进入 `(0.005, 0.1]`，且触发前 BTC 有效点数 `npts >= 8`；
- G1：`G0 ∩ body_r <= 0.35`；
- G3：`G0 ∩ chg_bps <= +2.82`。

当前最值得做的优化不是继续扫描 `body/chg/q/t` 阈值，而是依次解决四个问题：

1. **测量是否可信**：15 秒快照、缺失、重启和历史重放是否系统性改变样本；
2. **edge 来自哪里**：预测市场错价、BTC 上冲衰竭、时间价值错估，还是薄盘坏价；
3. **edge 能否成交**：触发价到询价、成交和 FOK 重试的实际落差；
4. **怎样承担风险**：同一母事件下三笔同方向订单是否只是重复杠杆。

研究采用“全窗口审计 → 唯一 G0 母事件 → G1/G3 标签 → 统一执行反事实 → 组合政策”的结构。旧历史和已经查看过的数据只负责生成候选；协议冻结后新增的影子数据才负责确认。最终输出多目标 Pareto 前沿，不用单一胜率或单一 EV 选冠军。

## 2. 研究目标与非目标

### 2.1 最终目标

穷尽 G0/G1/G3 可合理提出的优化角度，并将每个方向写成可证伪假设，使候选能够在以下维度上接受统一裁决：

- 可成交净 EV；
- 每个 G0 母事件的机会价值；
- 触发频率和成交覆盖；
- 日级尾部风险、最大回撤和恢复期；
- 跨周、趋势、波动、时段和流动性状态的稳健性；
- 数据质量敏感性；
- 规则复杂度和自由参数数量。

### 2.2 非目标

本文不做以下事情：

- 不把历史最高 EV 规则直接接入真钱；
- 不修改当前 G0/G1/G3 开关、金额、日限或执行价护栏；
- 不把 2026-08-24 之后的历史段重新称为独立 holdout；
- 不把 G1、G3 与 G0 当作独立样本；
- 不用平均报价代替逐事件报价；
- 不用已成交子集的收益代表全部信号事件；
- 不在看到未来期中途输赢后修改阈值或提前停表；
- 不以全 Kelly 或连续仓位优化作为首批方案。

## 4. 研究架构

### 4.1 三层分析单位

#### 全窗口层

每个 5m 窗都进入审计母表，包括：

- 无首触；
- UP/DOWN 或 BTC 缺失；
- `npts < 8`；
- 重启、恢复或 API 故障；
- 无法结算；
- 数据完整但零触发。

此层用于估计发生率、缺失机制和从全市场到最终成交的完整漏斗。

#### 唯一母事件层

每个窗口至多一个 G0 母事件。G1、G3 是标签，不是新事件。每个 G0 必须唯一归入：

1. `both = G1 ∩ G3`；
2. `g1_only = G1 \ G3`；
3. `g3_only = G3 \ G1`；
4. `neither = G0 \ (G1 ∪ G3)`。

四层互斥且完备，加总必须严格等于 G0。

#### 策略政策层

同一母事件上离线重放多个互不影响的政策：

- G0、G1、G3、G7 及其预注册子规则；
- 统一执行价护栏；
- 不同规模和重试政策；
- 当前三通道叠加；
- 单母事件共享预算；
- 粗粒度分数仓位和 regime 降仓。

### 4.2 三种收益口径

三种口径必须同时报告且不可互换：

1. **Intention-to-trigger**：所有门命中事件，以触发价衡量信号机制；
2. **Guard-eligible**：使用统一 quote、护栏、规模、延迟和重试政策得到的反事实可成交收益；
3. **Actual-filled**：当前生产执行机制选择后的真实成交收益。

| P4 | 若估计不确定，粗粒度 `{0,.25,.5,.75,1}` 仓位改善前沿 | 固定仓位 vs 粗分数仓位 | 无任何样本外非劣点 |
| P5 | 若赔率与置信度可校准，保守 edge 档位优于通道定额 | 固定额 vs 收缩后 edge 档位 | edge 档与未来收益不单调 |
| P6 | 若亏损日内聚集，日预算或预注册降仓改善尾部 | 固定仓位 vs 聚集降仓 | 只降收益、不降尾部 |
| P7 | 若某 regime 明确有害，条件降仓优于静态参数 | 静态 vs 二元 regime 折扣 | 交互不稳或最差层未改善 |
| P8 | 若风险主要来自同窗/同日累积，硬上限降低破产风险 | 无共享限制 vs 单窗/日上限 | 压力测试中无改善 |
| P9 | 若首触族与其他实盘通道共享行情暴露，全组合风险高于族内风险 | 独立预算 vs 跨族组合预算 | 相关性和尾部不增加 |
| P10 | 若证据恶化或数据异常时停火有价值，预注册降级/恢复规则改善生存 | 无规则 vs 证据/质量型停火 | 机会成本超过风险改善 |

Kelly 只作为压力对照，最高测试 1/8–1/4 Kelly，并受绝对单窗和单日上限约束；不作为首批上线候选。

### 5.7 F：强制反证与稳健性

| ID | 强制反证 | 通过要求 |
|---|---|---|
| F1 | 将特征时间错位到前/后相邻窗口 | 真规则显著优于错位 placebo |
| F2 | 日内或块级随机置换 outcome | 真效应不能由同样强的置换结果频繁复现 |
| F3 | 镜像 UP、15m 或不应有效的周期负对照 | 不出现无差别“到处有效” |
| F4 | leave-one-week-out | 不依赖单一周，符号大体一致 |
| F5 | 1/3/5/7 日块 bootstrap | 主结论不因合理块长翻转 |
| F6 | 阈值邻域扰动 | 邻域平滑，不只精确切点有效 |
| F7 | 缺失极端界限与 IPCW | 结论不在合理缺失情景下反转 |
| F8 | 悲观滑点、胜率下调、连败翻倍、相关性=1 | 候选仍满足预注册风险约束或被明确否决 |
| F9 | 删除最大赢家、最优日和最优周 | 不能只靠一个巨额赢家或一个 regime |

- `body_r` 的多个邻近阈值；
- `chg_bps` 的多个邻近阈值；

- `npts` 稀疏/完整分层；

## 7. 首批候选与优先级

优先级按“辨识价值 × 实盘价值 × 可测性 ÷ 过拟合自由度”确定：

### P0：地基和第一批影子

### P1：机制增量

1. G7 相对父规则的 `streak_up <= 1` 增量；
2. 固定 45 秒路径斜率和减速；
3. 从高点回撤比例；
4. 标准化障碍距离；
5. UP+DOWN 和价一致性。

### P2：新增观测后开放

1. 5m 与 15m/现货/永续的孤立过冲；
2. 流动性冲击比和盘口深度；
3. G7 strict；
4. quote ladder、拒单恢复和 FOK 重试政策。

### P3：账本成熟后开放

1. 母事件共享预算；
2. 四层交易/跳过；
3. 粗粒度分数仓位；
4. regime 降仓；
5. 跨全部实盘通道的组合风险上限。

## 8. 指标与 Pareto 裁决

### 8.1 经济指标

设候选门为 `A_g`，在冻结执行政策下的单位风险收益为 `R`：

- 条件净 EV：`E[R | A_g=1]`；
- 机会价值：`V_g = E[A_g R]`，跳过事件记 0；
- 逐事件盈亏平衡校准差；
- 门命中率、有效日事件率、统一护栏通过率、quote 成功率和 fill rate。

机会价值是首要经济锚点，因为它同时反映质量与频率。条件 EV 很高但几乎不触发的规则不能自动胜出。

### 8.2 风险指标

所有政策按固定 1 USDT 风险单位、100 单位参考资本、无复利追加的账本重放；跳过记 0，同一母事件的多笔现状订单按真实总风险计入。由此，20%、30%、50% 资本回撤分别对应从历史权益高点下跌 20、30、50 个风险单位：

- 日收益 10% 分位；
- CVaR95 和敏感性 CVaR97.5；
- 最大回撤和 CDaR；
- 最长恢复期；
- 最差单日和最差连续 5 日收益；
- moving-block bootstrap 下达到 20%、30%、50% 参考资本回撤的概率；
- median-of-means EV 和 leave-one-week-out 方向一致率。

Sharpe 不作为主裁决指标。CVaR 改善百分比一律指尾部平均损失绝对值相对下降，避免负收益的符号歧义。

### 8.3 Pareto 支配

所有收益差异均按固定 1 USDT 风险单位计算。A 支配 B 必须同时满足：

1. A 的所有硬安全指标不差于 B；
2. A 至少满足一个核心实际改善：可成交条件 EV 提高 `>= 0.10`，或每个 G0 母事件的机会价值提高 `>= 0.02`，或 CVaR95 尾部平均损失绝对值下降 `>= 10%`；
3. A 相对 B 的机会价值下降不超过 `0.01 / G0 母事件`，统一护栏成交率相对下降不超过 10%；
4. A 在任何信息充分的关键 regime 中，其机会价值相对 B 的 95% CI 下界不得低于 `-0.05 / G0 母事件`；
5. A 的数据质量和成交率没有不可解释的恶化；
6. 若经济和风险差异都不明确，优先保留自由参数更少的规则。

上述数值是本轮确认协议的最小实际差异，不随未来结果修改。互不支配或区间重叠时，两者共同留在 Pareto 前沿，不用点估计强行排序。

## 9. 统计协议

### 9.1 分析和聚类

- 5m 窗口是抽样与配对单位；
- UTC 日是主要推断聚类单位；
- G1/G3/G7 与父规则在同一母事件集合上做配对比较；
- 每次重采样整日共同抽取全部规则，保持嵌套关系；
- 主区间使用 3 日 moving-block bootstrap，20,000 次；
- 1、5、7 日块作为敏感性分析；
- 同时报告日随机截距的层级模型作为佐证，但不替代非参数主分析。

### 9.2 多重检验

预注册检验树：

- Family A：G0/G1/G3 在统一执行口径下是否保有正价值；
- Family B：G1−G0、G3−G0、G1−G3 的配对增量；
- Family C：新机制候选；
- Family D：regime 和安全否决。

执行规则：

1. G0 明确失效时，不开放首触机制的升级子树；
2. 父主效应不存活时，不开放交互子树；
3. 开放节点内使用 BY-FDR 5% 或日级 Westfall–Young；
4. 安全否决使用 Holm/FWER；
5. 历史 p/q 值不计入新确认检验；
6. 胜率检验不能代替逐事件净 EV 或配对机会价值检验。

### 9.3 阈值与模型选择

连续阈值只允许在旧探索集内通过 nested rolling-origin CV 选择：

- 外层时间前推；
- 内层仅使用外层训练段选择参数；
- purge 相邻窗口并 embargo 至少一个 UTC 日；
- 合并外层测试预测后估计探索效应；
- 正式未来期开始前冻结公式、阈值、缺失处理和执行政策。

前向期间不得查看候选级盈亏后改规则。运营人员可以查看样本覆盖、错误率和服务健康，但候选收益汇总应盲化或只在预注册裁决时打开。

## 10. 信息量与停止规则

正式裁决必须同时满足：

- 至少 28 个有效 UTC 日；
- 覆盖至少 4 个完整周；
- G0 至少 200 个母事件和 20 个 DOWN 胜例；
- 每个待升级候选至少 60 次命中、15 个胜例、20 个有触发日；
- 父子配对增量至少 40 个有效贡献窗口；
- 日级 ESS 至少 20；
- 主 EV 95% 区间半宽不超过 0.25 单位风险；
- 关键 regime 每层至少 8 个有效日。

有效日定义：当日 288 个 5m 窗中至少 95% 有 `window_audit` 行；这些已审计窗口中至少 95% 各有 8 个有效 BTC 点且 UP/DOWN 报价非空；所有可判定窗口完成结算；当日无持续超过 30 分钟的采集故障。数据完整但零触发的日仍计入频率分析。未满足条件的 UTC 日不计入最短日数，但必须保留并报告，且不得从收益估计中按表现选择性删除；主分析同时给出纳入全部日的缺失敏感性结果。

未达到信息量不是失败，而是“信息不足”。所有候选统一延长 14 个完整 UTC 日，最多延长到 84 日；不得只给表现好或表现差的臂补样本，也不得因为中途盈利提前停止。达到 84 个有效日仍未满足候选信息量门槛时，该候选以“低频、无法在本实验预算内确认”结束本轮，不升级、不继续无限补样本；如未来重启研究，必须新建协议和确认时钟。

## 11. 一次性裁决规则

### 否决

满足任一项即否决或退回机制层：

- 可成交净 EV 的 95% CI 上界 `< 0`；
- 信息充分的关键 regime 出现实质有害效应；
- 结果由单一周、单一赢家或数据缺失假设驱动；
- intention-to-trigger 与 actual-filled 的差异无法解释；
- placebo 或负对照同样有效；
- 数据或执行偏差无法界定。

### 继续影子

满足任一项则继续收集：

- 任何信息量门槛未达到；
- 区间同时跨越否决和升级界值；
- 位于 Pareto 前沿，但没有明确支配当前冻结基线；
- 某关键层信息不足。

### 进入 Pareto 前沿

必须同时满足：

- 通过所属检验家族的 gate 和多重校正；
- 统一执行口径下净 EV 下界高于 0；
- 机会价值、成交覆盖和尾部风险无硬伤；
- 跨周和关键 regime 稳健；
- 全部强制反证通过；
- 数据完整性达到预注册标准。

### 申请实盘升级

进入 Pareto 前沿不等于自动改实盘。候选只有在相对当前冻结基线达到预注册实际改进后，才能提出单独的实盘变更申请；任何开关、金额、护栏、仓位或互斥关系修改仍需用户明确批准。

## 12. 最小观测架构

### 12.1 `window_audit`

每个 5m 窗一行：

- `window_start/window_end`；
- expected/actual sample count；
- first/last sample timestamp、最大 gap；
- UP/DOWN/BTC 缺失数；
- entry/exit 锚点来源；
- restart/recovery 标志；
- archive/settlement 状态；
- 是否首触、为何被排除。

### 12.2 `firsthit_mother_event`

每个 G0 母事件一行：

- `window_start/trigger_ts/detected_at`；
- `q_prev/q/Δt`、同步 UP 价和和价偏差；
- BTC open/trigger/high/low；
- body/chg/wick/range/npts；
- 45 秒斜率、前后斜率差、从高点回撤、跳跃占比；
- dvol/dpar 与缺失指示；
- G1/G3/G7 标签和四互斥层；
- 特征版本、配置版本、代码 commit。

### 12.3 `execution_observation`

与真钱订单分离的只读观测：

- detected/task-created/lock-enter/quote-request/quote-response/place/confirm 时间戳；
- 一条母事件级基准 quote；
- quote size、average price、有效期和原始响应；
- 完整 FOK attempt ledger；
- 拒单后的预注册短时 quote 路径；
- 抽样式多规模 quote ladder；
- 错误码、超时、限流和停止原因。

### 12.4 `counterfactual_policy`

离线政策定义：

- 候选 gate；
- 统一护栏；
- 规模；
- 延迟和重试政策；
- 单窗/单日预算；
- regime 折扣；
- 版本和冻结日期。

每个母事件、每个政策输出 eligibility、fillable、counterfactual PnL 和跳过原因，不提交订单。

## 13. 数据流与故障隔离

```text
15 秒原始采样
  ├─ 当前 G0/G1/G3 实盘链路：保持不变
  └─ 只读研究旁路
       ├─ 写 window_audit
       ├─ 写唯一 mother_event 与候选标签
       ├─ 异步 execution_observation
       ├─ 结算后补 outcome
       ├─ 离线重放 counterfactual_policy
       └─ 到期一次性 Pareto 裁决
```

硬约束：

- 研究旁路不得获取当前 `_trade_lock`；
- 不得阻塞、延迟或改变真钱任务；
- quote 观察失败只记失败，不形成真钱重试；
- 新采集必须有速率上限、超时和独立任务边界；
- 研究 DB 失败不得影响真钱链路；
- G0/G1/G3 当前 version、护栏、金额、日限和历史行保持不变；
- 每个新候选从实际部署时刻独立起钟，不追溯计入已查看数据；
- 公式或字段语义变化必须新建版本，禁止静默覆盖；
- 产物记录代码 commit、配置快照、输入区间和数据哈希。

## 14. 测试与验收设计

### 14.1 信号语义

- q=0.005 不触发，q=0.1 触发；
- body=0.35 和 chg=2.82 含边界；
- npts=7 拒绝，npts=8 接受；
- 删除触发后全部点，任何 ex-ante 标签不得变化；
- 变异测试故意读取未来点时必须失败。

### 14.2 母事件与嵌套

- 同窗三门全中仍只有一个 mother event；
- 四互斥层互斥完备并严格加总到 G0；
- G1/G3 不得将同一 window 重复扩大统计 n；
- 重启和重复处理保持幂等。

### 14.3 收益与执行

- 触发价、统一 quote、实际 fill 三套 EV 使用手算案例交叉验证；
- `avg_price == guard` 必须拒绝；
- FAILED 报价不得标记为 fill；
- FOK 多次尝试完整保留且顺序一致；
- counterfactual 政策永不触发 place order。

### 14.4 缺失和隔离

- 无 BTC、采样 gap、quote 失败和无法结算均保留审计行；
- 缺失 dvol/dpar 必须保持 NULL 并另有缺失指示，不填 0；
- 研究观察超时、DB 异常或 quote 异常时，当前真钱调用次数和参数不变；
- 研究任务不能获取实盘交易锁。

### 14.5 统计验证

使用合成数据验证：

- 3 日块 bootstrap 的配对和聚类保持正确；
- BY/Holm 和 hierarchical gatekeeping；
- Pareto 支配和复杂度 tie-break；
- 信息不足与全体统一延长；
- 单周赢家、单一巨额赢家、随机 outcome 和时间错位不能升级；
- 数据缺失 IPCW 和极端界限敏感性。

交易链路相关改动必须补 `tests/test_multi_live_trader.py`，并运行全量后端测试。第一阶段不需要改前端；若未来增加面板，需执行前端构建并在浏览器验证黄金路径和边缘状态。

- 仅对明确改善者提出实盘变更申请。

## 16. 已知方法学问题

当前未提交研究脚本可用于候选生成，但不能直接作为正式裁决器：

- `scripts/comprehensive_firsthit_backtest.py` 在同一 calib 上选择并估计大量嵌套阈值；
- FDR 检验的是胜率相对 G0 基准，而不是净 EV 或父子配对机会价值；
- 重复规则曾以不同名字进入检验池；
- post-split 段已烧过，虽然当前输出已标记为弱证据，仍不具独立确认资格；
- `scripts/audit_firsthit_backtest.py` 的 25/25 一致性证明两份实现重现了同一数字，不证明检验 estimand、嵌套处理和缺失处理正确；
- 审计脚本把缺失 dvol/dpar 填为 0；
- 旧护栏分析以触发 q 代理真实成交价，只能是执行选择效应的一阶近似。

正式实现必须替代这些方法学薄弱点，而不是只给当前脚本增加更多规则。

## 17. 完成标准

本研究目标只有在以下交付全部存在并通过审计后才完成：

1. 七大家族、57 个假设的冻结注册表；
2. 全窗口数据质量漏斗；
3. 唯一 G0 母事件账本和四互斥层；
4. intention、guard-eligible、actual-filled 三种收益口径；
5. 统一执行反事实评估器；
6. G7 等候选的独立前向影子版本；
7. 配对、聚类、多重校正和 Pareto 裁决器；
8. 强制 placebo、稳健性和压力测试；
9. 至少 28 个有效日及全部信息量门槛；
10. 带证据等级的最终 Pareto 清单和实盘变更建议。

本文批准的是研究设计，不代表上述实现和前向验证已经完成。
